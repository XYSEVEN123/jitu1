一、项目概述

本项目基于 Python + Taichi 实现粒子物理交互仿真系统，通过 GPU 并行计算完成大量粒子的受力、运动、碰撞模拟，并支持鼠标实时交互，属于计算机图形学与物理仿真入门实践项目。

二、项目架构
1. 项目目录结构

```
plaintext
CG-Lab/
├── src/
│   └── Work0/
│       ├── __init__.py    # 模块标识
│       ├── config.py      # 全局参数配置
│       ├── physics.py     # 物理计算核心
│       └── main.py        # 程序入口与渲染
├── .gitignore
├── pyproject.toml         # 依赖管理
└── README.md
```

2. 模块职责
    
    config.py：统一管理粒子数量、物理系数、窗口大小、颜色等参数，方便调试与修改。
    
    physics.py：使用 Taichi 内核实现粒子初始化、受力计算、速度更新、边界碰撞等物理逻辑。    
    
    main.py：创建窗口、处理鼠标输入、驱动物理更新、完成每一帧的渲染绘制。
    
    init.py：标识 Python 包，保证模块可正常导入。

三、代码逻辑

1. 配置层（config.py）

    集中定义全局常量，实现配置与逻辑分离，便于快速调整效果：粒子总数、引力强度、阻力系数、反弹系数、窗        口分辨率、粒子大小与颜色

2. 物理计算层（physics.py）

    使用 Taichi 字段在显存中存储粒子位置与速度。

    初始化粒子随机位置。

    每一帧并行计算：粒子与鼠标的引力、空气阻力减速、速度与位置更新、边界弹性碰撞处理

3. 渲染与主控层（main.py）

    初始化 Taichi 与 GUI 窗口。

    循环：获取鼠标位置 → 更新物理 → 绘制所有粒子。

    实现实时交互与流畅动画。

四、实现功能

    1.GPU 并行加速：支持大量粒子高性能仿真。

    2.鼠标引力交互：粒子会被鼠标位置吸引、聚集、跟随移动。

    3.完整物理效果：引力、阻力、边界弹性碰撞。
    
    4.参数化可调：通过配置文件修改效果，无需改动核心逻辑。

    5.模块化设计：配置、物理、渲染分离，结构清晰、易于扩展与维护。
